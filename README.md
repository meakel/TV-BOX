# MacTVBox (Apple TV 风格 macOS 客厅电视盒子系统)

MacTVBox 是专门针对 macOS 打造的大屏电视盒子应用（10-foot UI）。
界面设计全面深度参照 **Apple TV (tvOS)**，当你将 Mac mini、Mac Studio 或 MacBook 通过 HDMI 连接到客厅电视或投影仪时，拿起 **Xbox 无线手柄**，即可沉浸式体验**哔哩哔哩、腾讯视频、抖音**等主流流媒体，并**全自动识别并拉起 Mac 本地安装的各种软件**（如 IINA、VLC、网易云音乐、Steam 游戏等），彻底告别鼠标与键盘！

---

## 🌟 核心特色

1. **Apple TV (tvOS) 沉浸式视差界面**
   - **Top Shelf 顶部视差展架**：焦点移动时，顶部平滑动态切换高清海报背景、应用介绍、4K/手柄标签与呼吸光晕。
   - **Focus Ring 3D 呼吸光环**：Xbox 摇杆移至卡片时，触发 1.1x 微浮起放大、纯白光轮与软阴影扩散。
   - **分类标签栏**：支持一键切换【全部应用】、【精选流媒体】与【电脑本地软件】。

2. **自动扫描发现电脑中的本地软件 (Native App Discovery)**
   - 内置 `AppScanner` 引擎，全自动检索 macOS 系统 `/Applications` 及用户应用目录。
   - 原生提取已安装 App 的高清图标与应用名称，智能优先排序常用影音工具（IINA, VLC, Infuse, 网易云, Steam 等）。
   - 按 Xbox **A 键**即可通过 `NSWorkspace` 原生无缝拉起。

3. **专属流媒体手柄适配引擎 (WebAdapters)**
   - **哔哩哔哩 (B站)**：过滤弹窗广告，注入大屏 CSS，接管键盘快进快退与选集。
   - **腾讯视频**：全自动最大化播放界面，手柄全屏控制。
   - **抖音短视频**：沉浸大屏模式，**手柄摇杆/十字键上下推直接刷下一个/上一个视频**，X 键一键点赞。

4. **原生防息屏机制 (IOKit Power Management)**
   - 自动向 macOS 内核申请 `kIOPMAssertionTypePreventUserIdleDisplaySleep` 断言，播放过程中无需触碰鼠标键盘也不会黑屏休眠。

## 🎮 Xbox 控制器交互映射表

| 手柄按键 | Apple TV 主屏动作 | 视频播放页动作（B站 / 腾讯视频 / 抖音） |
| :--- | :--- | :--- |
| **A 键 (绿色)** | 确认打开选中的应用 / 本地软件 | 视频 播放 / 暂停 |
| **B 键 (红色)** | - | 退出播放器，瞬间退回 Apple TV 主屏 |
| **X 键 (蓝色)** | **快速轮换分类标签** (全部/流媒体/本地) | 切换全屏模式 / 抖音点赞当前视频 |
| **Y 键 (黄色)** | 打开 / 关闭手柄按键指南 HUD | 打开 / 关闭手柄按键指南 HUD |
| **左摇杆 / 十字键** | **上下左右 2D 网格平滑移动焦点** | 左右快进快退 / **抖音上下滑切短视频** |
| **LB / RB (肩键)** | - | 上一集 / 下一集 / 快速切视频 |
| **LT / RT (扳机键)** | - | 快退 10 秒 / 快进 10 秒 |

> **💡 调试备用**：未连接手柄时可使用键盘调试：
> - `方向键`：网格焦点移动 / 快进快退 / 抖音刷视频
> - `Enter (回车)`：等同于 Xbox A 键
> - `Esc`：等同于 Xbox B 键
> - `F 键`：等同于 Xbox X 键
> - `H 键`：等同于 Xbox Y 键

## 🚀 在 macOS 上的构建与运行

### 方式一：终端命令行直接运行
```bash
# 进入工程目录
cd /path/to/MacTVBox

# 直接启动应用
swift run
```

### 方式二：Xcode 打开运行
1. 打开 Xcode，选择 `File` -> `Open...`。
2. 选择本项目的根目录（包含 `Package.swift` 的文件夹）打开。
3. 运行目标选为 `My Mac`，点击顶部 Run（`⌘R`）即可编译运行。
